# Research result index

This directory contains lightweight, reviewable summaries rather than raw benchmark data. The canonical machine-readable index is `exploratory-summary.json`.

The summary is transcribed from the dated research reports in `docs/`; it was **not** independently recomputed from raw artifacts in this repository. Raw RoboArena metadata, HELM predictions, manifests, and full generated outputs remain outside Git to respect the data boundary and size limits.

Use [docs/reproducibility.md](../docs/reproducibility.md) to retrieve the public inputs, verify hashes, and regenerate the full result file. A confirmatory result must use a frozen independent evaluation protocol; these exploratory summaries must not be relabeled as confirmatory.
